## 这是什么

一个完整的浏览器 FPS，整个游戏压在一个 HTML 文件里：

- **947KB**，three.js r185 内联，没有任何外部资源
- **双击即玩**，不需要服务器、不需要 npm、不需要联网
- **164fps @720p**（本机实测）
- 赛博朋克霓虹雨夜场景

## 为什么做成单文件

发给别人玩，最烦的是「先装环境」。

单文件的意思是：你把这个 `.html` 拖进微信发给朋友，他双击就能玩。没有 node_modules、没有构建步骤、没有 CORS 报错。

代价是所有代码都在一个文件里，所以源码另开 `_src/` 目录维护，改完跑构建脚本合并。

## 目录

```
├── index.html          可直接运行的完整游戏（构建产物）
├── _src/
│   ├── src/            分模块源码
│   │   ├── 00-util.js
│   │   ├── 10-core.js
│   │   ├── 20-world.js
│   │   ├── 30-weather.js
│   │   ├── 40-weapon.js
│   │   └── 50-game.js
│   ├── three.bundle.js three.js 内联包
│   └── build.py        合并构建脚本
└── LICENSE
```

## 怎么改

**不要直接改 `index.html`**，改 `_src/src/` 里的模块，然后：

```bash
python _src/build.py
```

重新生成 `index.html`。

## 技术要点

- **零模型文件**：所有几何体代码生成，没有 glb/fbx 要加载
- **雨夜氛围**：体积雾 + 动态雨幕 + 霓虹反射
- **移动与射击**：指针锁定 + 射线检测命中
- **帧率优先**：几何体合并、材质复用、按需渲染

## 兼容性

现代 Chromium / Edge / Firefox / Safari。需要 WebGL2。
